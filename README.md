# 街垒 / Barricade

跟着音乐节拍守住街垒的 2D 节奏防守游戏。灵感来自《悲惨世界》与 1832 年巴黎共和党人起义。

> 状态：可玩原型。两关串成一局——场景 1 用 100 秒攒街垒血量，过场后进入场景 2 防守。

## 玩法

**场景 1 · 建造（100 秒）**

- 屏幕提示 A/D/W/S，在 Perfect 窗口内按下 → 街垒 +10 血（上限 1000）
- 按错字母进入 3 秒 REST，期间不能得分，倒计时结束后换新提示
- 有音乐时 Perfect 由歌曲强拍决定；没有音乐时是自走的节奏计时器
- 100 秒结束进入过场，攒下的血量带进下一关

**场景 2 · 防守**

- A/D 换攻击轨道（三条），W/S 切换空中／地面瞄准，Space 开火
- 完美命中 100 伤害（一击必杀），普通 50（两枪）；每次开火后 1 秒换弹
- 完美弹实际命中会立即结束换弹；切换轨道或瞄准后有 0.15 秒禁射
- 敌人撞墙扣 10，敌弹扣 1，手榴弹扣 50；玩家子弹穿墙
- 血条满格 = 进入场景 2 时继承的血量，不是固定 1000

## 运行

1. Unity Hub 添加本目录，用 **2022.3.62f3c1** 打开
2. 首次导入会生成 `Library/`（已忽略，不纳入版本库）
3. 打开 `Assets/Scenes/2.unity` 直接 Play；Build Settings 已包含场景 1 与 2


脚本模块划分与常用改动位置见 [Assets/Script/README.md](Assets/Script/README.md)。

## 音频

- **音乐**：`Rhythm/RhythmManager.cs`，按 DSP 时间与逐拍时间表调度，支持动态 BPM 与强拍 Perfect
- **音效**：`Audio/SfxPlayer.cs`，从 `Assets/Resources/SFX/{编号}` 加载（如 `SFX-PLY-01.wav`），12 路声源池；编号带 `-V1..V3` 变体时随机轮换，缺变体自动回退到基础文件
- **心跳**：`Audio/HeartbeatAudioOutput.cs` + `Resources/SFX/HeartbeatPulse/Pulse-V1..V3.wav`。每个心动周期排两次单跳（第二击 0.55 倍音量），按“预计听到”的时间提前提交 DSP 排程，在 Perfect 间隔内自动停跳
- 音效命名规则：`SFX-<模块>-<序号>`，变体加 `-V2`、`-V3`

## 已知限制

- **街垒血量归零没有结算流程**，游戏不会结束，这是目前最大的缺口
- 火炮、环境音、人群声尚未实现，对应音效编号已预留但接不上
- 敌人动画生成器的校验报告仍是失败（`Grenadier_Idle` 时长判定），重建会抛异常
- 没有音频延迟校准界面，换耳机或蓝牙后会感到 Perfect 偏移
- 场景 1 的过场还是 10 秒占位，没有真正的 Timeline

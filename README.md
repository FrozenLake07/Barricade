# 街垒 / Barricade

心跳驱动的2D节奏防守原型，十章讲述街垒的一夜。Unity **2022.3.62f3c1**。

## 运行

Unity Hub打开本工程，等待导入，打开 `Assets/Scenes/Title.unity` 后Play。黑屏任意键开始；首次可校准音量/声音延迟，标题F2可重新调音。构建顺序为Title、1、2，十章复用两份玩法场景。

直接从场景1/2运行仍是旧调试模式，不能用来检查完整战役。

## 操作

- 建造：A/D/W/S单键与跨手双键；双键两键间隔≤120ms且均在窗口内为Perfect。错误进入3秒REST。
- 防守：A/D换轨，W空中、S地面，Space射击，R换弹；每拍一枪。Perfect窗口R立刻换满，不占射击资格。
- 第7章：Q放走、E处决；超时默认放走。第9章无限弹、每拍一枪，无胜利出口。
- Enter继续章节；失败R重试。防守F4查看波次诊断。

## 配置

`Assets/Resources/Campaign/ChapterTable.asset`管理十章拍数、双键、血量和过场接口；`Campaign/Waves`下16份资产管理A/B波次。每章183拍；一拍=等待+0.5秒判定窗口，最快1秒。短准备段满Perfect可达600；资源与连击已删除。

过场支持Prefab、Timeline、AudioClip、caption、完成信号和超时。正式过场与部分音效仍待填素材；当前使用文字占位与已有结尾演出。

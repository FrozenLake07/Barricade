## 开始编辑

1. Hierarchy 选中 TavernUI_AnimationStage → Timeline_酒馆。
2. 打开 Window → Sequencing → Timeline。
3. 三个人物各有“位移（录制 RectTransform）”和“动作（UI Image）”轨道，绑定已经完成。
4. 动作轨道目前各放了 4 秒待机占位，可以删除、拉长或替换。Timeline 不会自动开始播放。
5. 从 Assets/Cinematics/TavernUI/Animations 拖入 UI_Hero_Walk、UI_Enjolras_Walk、UI_Grantaire_Drink 等 .anim 到相应的动作轨道。
6. 需要走动时，在对应人物“位移”轨道录制人物根物体 RectTransform 的 Anchored Position，同时在动作轨道放行走片段。位置单位对应 320×180 舞台像素；没有按时间自动走动的脚本。

重要：原 Assets/Resources/HeroAnimations/Clips 中的片段绑定 SpriteRenderer，不能直接用于这里的 Image。请使用本次生成的 UI_Hero_*。这套 UI 主角不挂 HeroActor、建造或战斗控制脚本，Timeline 不需要额外调用 SetExternalControl。

## 填写特殊回应

Unity Project 中选择 Assets/Cinematics/TavernUI/Data/NameResponses.asset。
- Special Names：按列表顺序匹配；Aliases 是同一个名字的不同写法，完整匹配，忽略首尾空格、英文大小写及全角英文差异。已放入昂若拉 / Enjolras、格朗泰尔 / Grantaire 两组。
- Speaker：回应者的显示名字。
- Reply：回应台词；支持 {playerName}。例如占位符会替换为玩家确认后的名字。
- Default Response：普通姓名未命中特殊规则时使用。
- Unnamed Response：点击“暂不命名”时使用。无名回应不要依赖 {playerName}；按既有格式规则，名字为空时带该占位符的整条台词会为空。

本次所有 Speaker 和 Reply 均留空，没有代写叙事内容。Reply 留空或仅空格时会直接继续 Timeline；填入内容后，回应会停留，等待“继续”、Enter 或 Space。可在 Special Names 增加更多规则；重名别名以列表中第一个匹配项为准。

# 修改章节名字

在Unity顶部选择 **街垒 → 战役 → 编辑章节名字**。

窗口会集中列出10个章名。修改后点击“保存章名”，写入现有 `Assets/Resources/Campaign/ChapterTable.asset`，无需修改代码。保存前的输入只存在窗口草稿中。Ctrl+Z可以撤销；撤销后的资产按Unity常规方式保存。

“定位配置资产”会在Project面板中选中章节表，也可以展开 `Chapters`，直接编辑每章的 `Title`。窗口与Inspector编辑的是同一份配置。

章节入口、游戏HUD与最后的结束页均从章节表读取名字。第一章的四图演出沿用原显示方式，不额外叠加章名。

本次只增加编辑入口，现有章名保持；窗口保存时仅更新Title，不改章节编号、拍数、波次、字幕或配音接口。名字为空时提示填写。

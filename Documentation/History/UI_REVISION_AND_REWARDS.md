# 巴黎像素界面与第四章奖励（2026-10-21）

本轮沿用新版 `paris-retro-pixel-art` 技能及第一章已采用的画风，重做玩家界面的材质、配色和层次。旧金属弹匣面板改为深褐皮革与圆铅弹；菜单、暂停、校音、选择、抢救、结算、倒数采用旧纸与炭褐墨色。HUD、提示、建造字母及心形血量使用同一色板。原有像素准星保留轮廓，换弹进度改读真实装填状态。

## 奖励与保存

- 第四章三次出场视为同一个小孩的三段护送。只有三段全部成功、没有失败时，才在第三段结算后一次性增加 1 发携弹上限（3 → 4 发）；前两段成功不提前发奖，任意一段失败则不扩容。
- 扩容当下不额外生成已装填弹药：新位置先为空，完成普通或 Perfect 装填后装满新上限。新的防守场景按已解锁上限装满。
- 界面同时显示圆铅弹数量、当前余量/上限、永久扩容 `携弹上限 +N 发`；完整救援成功后显示一次 `携弹上限 +1` 提示，普通分段返回不提示扩容。第九章显示无限供弹。
- `RunState.AmmoBonus` 及 `ChapterStartAmmoBonus` 跨章保留，并经现有反射存档保存。重试第四章还原本章开始前的奖励；重试后续章节保留已获得奖励；新游戏清零。护送对象已结算后不会被存档重建而再次领奖。
- 既有护送装填效果继续跨章生效：无失败且成功三次为 0.8 倍装填时间；失败按原规则增至 1.5/2 倍。玩家界面不显示这些倍率、护送增益字样、对应颜色或数值通知；正常装填状态和真实进度仍可见。
- 试玩汇总新增 `ammo_capacity`，成功扩容记录 `ammo_capacity_reward` 事件。内部测试记录保留装填倍率，便于平衡分析。

## 编辑入口

1. `Assets/Resources/UI/Paris1832/Style.asset`：统一纸张、皮革、铅弹、标题字图、开始页背景和墨色/米白/深红色板。
2. `Assets/UI/Campaign/StartScreen.prefab`：编辑标题、校音/选择/结算共用卡片、HUD、提示、暂停与倒数页面的位置和字号。`ParisUITheme.useAuthoredLayout` 默认开启，运行时保留预制体布局。
3. `Assets/Resources/UI/AmmoHUD.prefab`：编辑弹药根节点、文字和图层；`LeatherAndLeadBalls/LeadBall1..6` 为六个显式铅弹位置。`CapacityReward` 仅表示携弹扩容，不显示隐藏装填效果。动态槽位布局由 `AmmoHudGraphic.SetState` 维护。
4. `ParisSceneUI.cs`：场景内建造提示、计数和心形血量的位置与染色。仍使用原 Canvas 的缩放方式。`OpeningCalibration` 仍控制心跳文字的字号脉冲与校音输入。
5. Unity 菜单 `街垒/界面/检查巴黎像素界面与护送扩容` 检查资源、图层、按钮、六槽和奖励保存；`街垒/界面/将巴黎样式保存到开始界面预制体` 保存统一材质/色板。

第一章四张图片、字幕/配音接口、章节改名入口、各章拍数、3–7 章难度和音乐编排沿用现行配置。正文仍使用 Silver；该字体缺少“垒”字，标题采用独立像素字图，避免标题出现宋体回退。
